# Is there an "emotional tone" direction inside an LLM — or just an instruction detector?

A small mechanistic-interpretability experiment on **Llama-3.1-8B-Instruct** (main) and **Qwen2.5-3B-Instruct**
(free replication). Short version of the results: [docs/SUMMARY.md](docs/SUMMARY.md). Every number:
[results/RESULTS.md](results/RESULTS.md) (generated by a script from the JSON files in `results/`).
Hypotheses were written down before the main runs: [docs/PREREG.md](docs/PREREG.md).

## The question

A common recipe for finding a concept in a model ("representation engineering", Zou et al. 2023; "activation
addition", Turner et al. 2023; "contrastive activation addition", Rimsky et al. 2024) goes like this:
give the model the same tasks under two opposite instructions (here: *"be warm and empathetic"* vs *"be cold
and robotic"*), record its internal activations, and take the average difference. That difference is a
**direction** in activation space, and people often call it "the emotion direction".

But the two groups of prompts differ in an obvious way: **the instruction text itself**. So the direction might
only be detecting "which system prompt is this?" rather than anything about emotion. This project tries to tell
those two stories apart.

## What we did (in plain words)

1. **Three datasets.**
   - **D1:** 150 neutral tasks ("Explain photosynthesis") with a warm or a cold system prompt (5 wordings each).
   - **D2:** 300 user messages that are emotional (grief, joy, fear, anger) or neutral, matched on topic and
     length, with **no** instruction about tone.
   - **D3:** the same contrasts in other formats (multiple choice, JSON, plain text without a chat template).
   - Train and test sets never share a topic (checked by a script).
2. **Reading (probing).** At every layer, at the last prompt token, we computed the D1 direction and a logistic
   probe. The key test is **transfer**: does the D1 direction, learned from instructions, also separate emotional
   from neutral *messages* in D2?
3. **Checking for shortcuts.**
   - A text-only classifier, to see if the words alone give the answer.
   - A probe that guesses *which* instruction wording was used.
   - A "control task" with random labels (Hewitt & Liang 2019), to see how much a probe can memorise.
   - A **negation test** ("Do *not* be warm…"), which has the warm words but the cold meaning.
   - Comparisons against random directions.
   - Removing a "format/instruction" subspace from the direction.
4. **Control (steering).** We added the direction (times a strength *c*) to the model's activations while it
   answered 60 new neutral questions, and compared four directions:
   - the D1 (instruction) direction;
   - the D2 (content) direction;
   - D1 with the format subspace removed;
   - a random direction, as a control.
5. **Scoring.**
   - An LLM judge (gpt-oss-120b, temperature 0, blind to condition, shuffled order) scored emotional intensity
     (1–10) and whether the task was still answered.
   - Fluency was measured as perplexity under the unsteered model.
   - Side effects: refusals, apologies and bullet lists.

## What we found

- **Reading the instruction is trivial, and that tells us little.** Every middle-to-late layer separates warm
  from cold instructions perfectly. But so does a simple word-count model on the prompt text. The model also
  records *which exact wording* was used.
- **The instruction direction does pick up emotional content (the headline).** On Llama it ranks emotional above
  neutral messages with AUROC 0.96 (1.0 = perfect, 0.5 = chance).
  - It does better than random directions.
  - It follows the *meaning* of an instruction, not its words: it gets the negation test 100% right, where the
    text model gets 0%.
  - But it does not clearly beat directions built from shuffled labels. The emotional and neutral messages are so
    different at the last token that many unrelated directions separate them too.
- **Steering with the instruction direction works.** Adding it makes answers warmer and gushier (the Moon
  becomes "a gentle giant who gives us a big hug"). The judge's score rises from about 2 to 6.3 at the strongest
  setting, the task still gets answered, and fluency suffers only moderately. Pushing the other way does little,
  because the default answers are already flat.
- **The direction learned from emotional content barely steers.** On Llama it is no better than random at
  moderate strength. It is also almost unrelated to the instruction direction (cosine 0.21).
- **The small model mostly agrees.** Steering behaves the same way on Qwen. Its transfer is weaker (0.84) and not
  clearly better than random directions.

**Verdict: mixed.** The pre-registered rule labels Llama "emotion direction" and Qwen "mixed". Our own reading is
stricter: what we found behaves more like an *"act warm" style/persona direction* than a general internal
representation of emotion. It does respond to emotional content, but the direction that the model's own
emotional content produces is different and has little causal effect.

## Limitations — please read before quoting any of this

- **Being able to read a concept is not the same as the model using it.** A probe finding a direction shows the
  information is *there*, not that the model relies on it. Steering is a stronger test, but adding a large vector
  is an unnatural thing to do to a model.
- **One judge, and no human check yet.** Emotional intensity was scored by a single LLM, which may have its own
  biases: it rates plain answers about 2/10 rather than 1/10. It was compared with a second LLM (Claude), not with
  a human (Spearman 0.80 on 40 outputs). Human labels are still pending (`results/human_labels.csv`).
- **Small datasets.** 150 D1 tasks, 150 D2 pairs and 60 steering prompts, all written for this project, and in
  English only. Confidence intervals are shown everywhere, but they do not cover how the prompts were written.
- **Steering scale is a choice.** We set the strength range by where fluency breaks (perplexity tripling).
  Different scales, layers or token positions could change the D1 vs D2 comparison. Only one layer per model was
  steered.
- **Only the last prompt token was probed.** Emotion in a message might live at other positions.
- **Two models, both instruction-tuned.** Results may not hold for base models or larger ones.

## Reproduce

```
pip install -r requirements.txt
python scripts/build_datasets.py && python -m pytest tests          # data + unit tests (local GPU)
python scripts/extract.py --model Qwen/Qwen2.5-3B-Instruct            # activations (Llama: modal_app.py stage1)
python scripts/run_probes.py --model Qwen/Qwen2.5-3B-Instruct
python scripts/run_steering.py --model Qwen/Qwen2.5-3B-Instruct       # (Llama: modal_app.py stage2)
python scripts/run_judge.py --model Qwen/Qwen2.5-3B-Instruct          # needs FIREWORKS_API_KEY in .env
python scripts/analyze_steering.py --model Qwen/Qwen2.5-3B-Instruct
python scripts/make_figures.py && python scripts/make_results.py
```

Figures are in `figures/` (F1 probes by layer, F2 cosine, F3 steering dose-response, F4 costs, F5 example
outputs). All generations are in `results/<model>/generations.jsonl` and judgments in `judgments.jsonl`. Total
compute cost: about $0.15 on Modal and $0.36 on Fireworks.
